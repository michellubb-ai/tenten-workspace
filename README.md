# Tenten workspace

A responsive, editable personal workspace, schedule and calendar for GitHub Pages.

## Public calendar

This site and repository include Tenten's full October–November calendar, event remarks, locations, study scopes and school notices. The published starting calendar is public.

The initial snapshot preserves the current saved events, completion flags, remarks and update times. It is loaded only when this browser has no saved workspace. Existing browser edits are kept after page refreshes and site updates.

## Editing and saving

Open the site on a phone or computer, then use **Add event**, event editing and **Notes & remarks**. Edits save in that device's browser. They do not automatically synchronize between devices or change the published starting calendar.

Use **Export backup**, transfer the JSON privately, and **Restore backup** on another device to move your latest events, remarks, notes and study references. Keep backups because clearing site data or using private browsing can remove browser records.

## GitHub Pages

This folder contains the complete app: **index.html**, **.nojekyll**, and this README. No build tools are required. In repository **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, and save.
